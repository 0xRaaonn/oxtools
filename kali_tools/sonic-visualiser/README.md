# Sonic Visualiser

## What it does

View audio waveforms, spectrograms, and frequency features.

## First steps

Open a WAV and add a spectrogram layer; zoom to suspect time/frequency.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

A challenge WAV displays a narrow-band pattern spelling digits in the spectrogram; note the time span and confirm with Audacity/SoX.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Display settings can hide faint signals; spectral patterns may be incidental.
