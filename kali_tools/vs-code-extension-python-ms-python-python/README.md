# VS Code extension: Python (ms-python.python)

## What it does

Provide Python interpreter selection, linting, and debugging in VS Code.

## First steps

Select the uv/venv interpreter and create a Python launch configuration.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Set a breakpoint inside a decoder loop, run a test byte string, and inspect intermediate bytes.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

The selected interpreter may differ from terminal Python; check version and environment.
