# G'MIC (gmic)

## What it does

Apply image filters and transforms through a powerful CLI.

## First steps

Run `gmic -h` and load an image with `gmic image.png ... output result.png`.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Use a contrast/threshold filter on a copied faint image to reveal hidden lettering, then compare with original pixels.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Filter syntax is version-specific and transforms can destroy steganographic bits; keep originals.
