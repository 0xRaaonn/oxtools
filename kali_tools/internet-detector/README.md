# internet_detector

## What it does

Check whether the environment has internet connectivity.

## First steps

Run the installed tool's help or documented default check; inspect its local README for flags.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Run it before an offline-only workflow; if it reports connectivity, still follow the contest's network policy and use local data where required.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Connectivity checks may contact external hosts; do not run if the event prohibits such traffic.
