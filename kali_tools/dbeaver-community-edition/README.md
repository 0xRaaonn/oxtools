# DBeaver Community Edition

## What it does

GUI SQL client for many database engines.

## First steps

Create a connection to the supplied lab database, inspect schema, then run read-only queries.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Connect to a competition PostgreSQL service, list tables, and query `SELECT count(*) FROM messages;` before drilling into rows.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Drivers may download; credentials and queries can touch a live service, so use organizer-provided scope.
