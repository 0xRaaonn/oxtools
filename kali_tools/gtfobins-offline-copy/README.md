# GTFOBins (offline copy)

## What it does

Look up documented behavior of Unix binaries that can matter in a lab privilege scenario.

## First steps

Search the local HTML/Markdown copy for a specific available binary and scenario.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

In an organizer-provided sandbox, check whether a permitted binary has a documented file-read mode, then test only within that sandbox.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Entries are conditional on version, permissions, and configuration; an offline recipe is not a guarantee.
