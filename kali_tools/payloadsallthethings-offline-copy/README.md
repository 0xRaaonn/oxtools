# PayloadsAllTheThings (offline copy)

## What it does

Local collection of web/security payload examples and technique notes.

## First steps

Search its Markdown with `rg -i 'topic' /path/to/PayloadsAllTheThings`.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Find a relevant input-validation example, adapt one harmless test to the lab, and inspect the actual server response.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Examples are context-specific and can be disruptive; validate scope and assumptions.
