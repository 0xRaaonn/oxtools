# Visual Studio Code

## What it does

Edit, search, and debug source files in a project.

## First steps

Open a copied challenge folder, use global search, then inspect source and debugger configuration.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Search a provided Python project for `verify`, set a breakpoint in the validator, and run a trusted test input.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Workspace tasks/extensions can execute code; inspect settings before trusting a downloaded project.
