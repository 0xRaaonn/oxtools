# VS Code extension: C/C++ (ms-vscode.cpptools)

## What it does

Provide C/C++ language navigation and debugging in VS Code.

## First steps

Open a C/C++ project and configure include paths/compiler and a launch configuration.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Set a breakpoint in a trusted C validator, debug with a sample input, and inspect variables beside the source.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

IntelliSense is not the compiler; debug configs can execute builds and targets.
