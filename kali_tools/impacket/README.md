# Impacket

## What it does

Python toolkit for network protocols such as SMB/Kerberos in lab environments.

## First steps

List installed examples and run each script's `-h`; e.g. `GetUserSPNs.py -h`.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

In an organizer-provided AD lab, use a read-only enumeration example to list available service principals and verify target/domain credentials.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Examples can authenticate or change remote state; choose only intended lab targets.
