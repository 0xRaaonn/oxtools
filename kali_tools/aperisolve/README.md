# AperiSolve

## What it does

Web-based image steganography analysis service.

## First steps

Open the permitted AperiSolve instance and upload only a challenge image allowed by event rules.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Upload a supplied PNG, compare bit-plane and metadata results, then independently verify an apparent payload with zsteg or HxD.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

An upload sends the file to a third party; never upload private evidence without authorization, and treat automated hits as leads.
