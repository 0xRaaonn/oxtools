# LibreOffice

## What it does

Open office documents, spreadsheets, and presentations.

## First steps

Open a copy in a restricted environment; inspect sheets, hidden rows/columns, comments, and document properties.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

A spreadsheet looks empty until you unhide a sheet containing a challenge clue; verify formulas and raw cell values.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Macros and external links may execute or fetch content; keep them disabled for untrusted files.
