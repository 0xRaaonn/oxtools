# IPython

## What it does

Enhanced interactive Python shell with history and inspection.

## First steps

Start `ipython`; use `object?` for help and `%run script.py` for a trusted script.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Load `Path('sample.bin').read_bytes()`, inspect slices and hex values interactively, then move the final logic into a reproducible script.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

History may retain secrets; interactive state can make results hard to reproduce.
