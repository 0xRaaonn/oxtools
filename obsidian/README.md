# Obsidian

## What it does

Organize local Markdown notes with links and search.

## First steps

Open a case folder as a vault; create notes linking evidence files and tool commands.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Make a note for a packet stream and link it to a recovered file and a hypothesis, then mark whether the hypothesis was verified.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Plugins can execute code or sync data; disable unnecessary plugins for sensitive CTF notes.
