# Miniforge3 (conda)

## What it does

Manage isolated Python and scientific-computing environments.

## First steps

Use `conda info`, `conda create -n ctf python=3.11`, and `conda activate ctf`.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Create a case-local environment for a Sage/Python parser and record `conda list` after reproducing the output.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Environment solves/downloads can use network and modify shell config; inspect packages and rules.
