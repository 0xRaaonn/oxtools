# obfuscator-io-deobfuscator

## What it does

Attempt to simplify JavaScript obfuscated by obfuscator.io.

## First steps

Run installed `--help` and provide a copied JS file as its README describes.

Use the installed program's help screen or local README to confirm option names before adapting a command. Keep supplied evidence unchanged and place outputs in a separate case folder.

## Worked example

Deobfuscate a string-array wrapper, locate a hidden endpoint, then verify that endpoint is actually used in the original script.

## How to interpret it

Treat a reported hit, recovered file, or successful run as one observation. Check the output against the original input, record the exact command or GUI steps, and verify a candidate flag or finding with a second view where possible.

## Pitfalls

Automated output can be incomplete or behavior-changing; compare with runtime requests.
